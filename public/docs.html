Autentikasi

no /api prefix

Endpoint untuk validasi akun user. Dipakai oleh halaman login dan dashboard.

POST

/validate

Validasi username & password. Mengembalikan session key jika valid. 
POST https://api.kazexnxx.my.id/validate
Content-Type: application/json

{
  "username": "user",
  "password": "secret",
  "androidId": "web-client",
  "version": "web"
}

// Respons
{ "valid": true, "key": "SESSION-...", "expired": false }
FieldTipeWajibKeterangan
usernamestringYAUsername akun
passwordstringYAPassword akun
androidIdstringTIDAKID perangkat, default web-client
versionstringTIDAKVersi client, default web
GET

/myInfo

Mengambil info profil user: role, expired date, dan status sesi. 
GET https://api.kazexnxx.my.id/myInfo?username=user&password=secret&androidId=web-client&key=SESSION-...
ParameterTipeWajibKeterangan
usernamestringYAUsername akun
passwordstringYAPassword akun
androidIdstringYAID perangkat
keystringYASession key dari /validate

API · Pembayaran

/api

Semua endpoint transaksi berada di bawah prefix /api. Autentikasi memakai API key user, bukan session.

GET

/api/create-qris

Membuat transaksi QRIS baru via query parameter — cocok untuk tes cepat di browser. Nominal minimum 1000. 
GET https://api.kazexnxx.my.id/api/create-qris?key=KAZEX-...&amount=1000
ParameterTipeWajibKeterangan
keystringYAAPI key user kamu
amountnumberYANominal transaksi, minimum 1000
POST

/api/create-qris

Versi JSON body — direkomendasikan untuk produksi. 
POST https://api.kazexnxx.my.id/api/create-qris
Content-Type: application/json

{
  "api_key": "KAZEX-...",
  "amount": 1000,
  "code": "qris"
}
FieldTipeWajibKeterangan
api_keystringYAAPI key user kamu
amountnumberYANominal transaksi, minimum 1000
codestringTIDAKDefault qris
GET

/api/qris-order-status

Mengecek transaksi milik user berdasarkan reference ID. 
GET https://api.kazexnxx.my.id/api/qris-order-status?key=KAZEX-...&reff_id=PAY-...
ParameterTipeWajibKeterangan
keystringYAAPI key user kamu
reff_idstringYAReference ID dari saat create QRIS
POST

/api/list-all-transaksi

Menampilkan daftar transaksi user dengan pagination. 
POST https://api.kazexnxx.my.id/api/list-all-transaksi
Content-Type: application/json

{
  "api_key": "KAZEX-...",
  "page": 1,
  "per_page": 15
}
FieldTipeWajibKeterangan
api_keystringYAAPI key user kamu
pagenumberTIDAKHalaman, default 1
per_pagenumberTIDAKJumlah per halaman, default 15

API · Maker

/api/maker

Endpoint pembuat gambar (image maker). Autentikasi memakai API key user. Respons berupa gambar atau URL gambar.

GET

/api/maker/fakelobbyff

Membuat gambar lobby Free Fire palsu dengan nama & detail yang bisa dikustom. Cocok untuk konten meme. 
GET https://api.kazexnxx.my.id/api/maker/fakelobbyff?key=KAZEX-...&nickname=KAZE
ParameterTipeWajibKeterangan
keystringYAAPI key user kamu
nicknamestringYANama tampilan di lobby
...mixedTIDAKParameter tambahan (rank, level, dll) menyesuaikan implementasi server
 
// Contoh pemakaian
const url = `https://api.kazexnxx.my.id/api/maker/fakelobbyff?key=${key}&nickname=${nick}`;

// Tampilkan langsung sebagai gambar
<img src="https://api.kazexnxx.my.id/api/maker/fakelobbyff?key=KAZEX-...&nickname=KAZE" />
